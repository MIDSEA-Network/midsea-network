# Logos

- `favicon.png` — the browser-tab icon (provided by request).
- `midsea-logo.svg` — a placeholder navbar wordmark (purple box with
  "MIDSEA Network" text) so the site builds cleanly out of the box.

Replace `midsea-logo.svg` with the real MIDSEA Network artwork when you have
it — same filename, or update the two references in `_quarto.yml`
(`website.navbar.logo` and `website.favicon`) to point at your new files.
